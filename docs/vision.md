# Fireworks

## 概要

スマートフォン・タブレットのブラウザだけで操作と花火表示が完結する、Unity Webの花火シミュレーションアプリ。縦横両向きに対応し、PCブラウザでも利用できる。

花火の打上げには、以下の入力方法を利用できる。

- キーボード
- マウス
- スマートフォン
- タブレット

ゲームではなく、花火を楽しむ体験を提供する。

---

# MVP

最低限実装する機能

- 花火を打ち上げる
- ランダム位置から打ち上げる
- ランダムな花火を選択する
- キーボード入力
- マウスクリック入力
- 同じブラウザ内でのタッチ入力

---

# 非目標

ゲーム性は持たせない。

スコアを付けない。

ランキングを作らない。

広告を表示しない。

課金要素を作らない。
