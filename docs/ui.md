# UI

## ブラウザ内の操作

スマートフォン・タブレットの縦横画面とPCブラウザに対応する。花火の描画と操作は同じ画面内で行う。
実行時UIはuGUI、日本語テキストはTextMeshProとNoto Sans CJK JPを使用する。

初期状態で設定パネルを閉じ、右下に小さな半透明の歯車アイコンだけを常時表示する。アイコンは24、透明なタップ領域は56（Canvas基準）、通常時の不透明度は0.45とし、Inspectorで調整できる。
設定・情報パネルを閉じている間に画面をタップまたはクリックすると、ランダムな花火を1回打ち上げる。
従来の遠隔操作の受付波紋に代わり、その画面で実際の花火を表示する。

サイズ・種類・基本色はFireworkSettingsの全候補から等確率で選ぶ。
文字花火の場合は設定パネルの入力文字列を使い、空ならランダムな英大文字1文字を使う。

## 設定パネル

歯車アイコンで開閉する。サイズ・構造・基本色・変化色を指定できる。
構造が文字花火の場合のみ最大6文字の入力欄を表示し、変化色は非表示にする。
通常花火は、構造が許可する場合のみ変化色を表示する。
指定打上ボタンとランダム打上ボタン、その下に「アプリ情報」ボタンを設ける。

画面全体はスクロールしない。設定内容が画面高を超える場合はパネル内をスクロールする。
パネル表示中の背景タップや、設定・情報ボタンの操作ではランダム打上しない。
タップとクリックをuGUIイベントに統一して二重発火を防ぐ。

## 情報パネル

設定パネル内の「アプリ情報」から開き、設定パネルを一時的に隠す。閉じると設定パネルへ戻る。
アプリバージョン、サードパーティーライセンス、閉じるボタンを表示する。
Webにはアプリ終了ボタンを表示しない。
ライセンス本文はスクロール表示し、Assets/StreamingAssets/ThirdPartyLicenses.txtをUnityWebRequestで読み込む。
Noto Sans CJK JPのOFL本文を同梱し、フォント付属OFL.txtも保持する。

## ブラウザ表示

Webテンプレートは利用可能な画面領域に追従し、セーフエリアを避ける。
ページの拡大・縮小とCanvas上のテキスト選択を無効にする。文字入力はブラウザのキーボードを使用する。
読み込み状況と失敗を表示し、準備完了後に「はじめる」ボタンを表示する。
PCブラウザではマウスカーソルを表示する。Slashで設定、Escapeで情報を切り替え、パネルを閉じている間はSpaceでも打ち上げられる。

## 実機確認

- iOS SafariとAndroid Chromeで縦横回転後にボタンとパネルが収まる。
- タップ1回につき1回だけ打ち上がり、UI操作中に誤発射しない。
- 日本語の入力・確定・削除、最大6文字、ソフトキーボードの開閉を確認する。
- 初回操作後に音声が再生され、バックグラウンド復帰後も操作できる。
- パネル、Dropdown、ライセンスをタッチで操作・スクロールできる。
