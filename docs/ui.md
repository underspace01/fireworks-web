# UI

## PC

通常はフルスクリーン。

パラメーターUIは初期状態で非表示とする。既定ではSlashキーで表示・非表示を切り替える。表示切替キーはInspectorから変更できる。

パラメーターUIが非表示の間はマウスカーソルを隠し、表示時に再表示する。既定ではEscapeキーでアプリ情報パネルを開き、アプリバージョン、サードパーティーライセンス表示ボタン、アプリ終了ボタンを表示する。情報パネルの表示キーはInspectorから変更できる。ライセンスパネルの表示中にこのキーを押すと、ライセンスパネルだけを閉じてアプリ情報パネルへ戻る。

パラメーターUIはuGUIで構築し、日本語テキストにはTextMeshProとNoto Sans CJK JPを使用する。

表示中は、以下をDropdownから選択できる。構造が文字花火のときだけ文字入力欄を表示し、変化色は表示しない。通常花火では、構造が許可する場合だけ変化色を表示する。

- サイズ
- 構造
- 基本色
- 変化色（選択したエフェクトが色変化を許可する場合のみ）

文字花火の入力は最大6文字とし、入力ラベルと入力欄は別の行に表示する。

指定内容で打ち上げるボタンと、ランダムで打ち上げるボタンを表示する。

アプリ情報パネルには「サードパーティーライセンス」ボタンを表示する。押すとスクロール可能なパネルを開き、各コンポーネントを「`===`、名称・著作権表示、`===`、完全なライセンス本文」の順で表示する。ZXing.NetのApache License 2.0本文とNoto Sans CJK JPのOFL 1.1本文は、`Assets/StreamingAssets/ThirdPartyLicenses.txt` にまとめてビルドへ同梱する。フォントに付属する `Assets/Art/Fonts/OFL.txt` も原本として保持する。

## スマホ・タブレット

初期状態では画面全体をランダム打上用の大きなボタンにする。ブラウザ側で、`FireworkSettings` に登録された牡丹・菊・変化菊・冠・文字花火などの全候補、サイズ、基本色をそれぞれ等確率で選び、選択結果を指定打上コマンドとして送信する。種類を追加した場合も、別途指示がない限り全候補を等確率とする。文字花火が選ばれた場合、文字入力欄に値があればその文字列を、空ならランダムな英大文字1文字を打ち上げる。

右下の歯車から設定パネルを開ける。設定パネルではサイズ・構造・基本色を指定して打ち上げる。構造が文字花火のときだけ、最大6文字の文字入力欄を表示する。通常花火では、構造が許可する場合だけ変化色を表示する。

ページ全体はスクロールしない。設定パネルの内容が画面高を超える場合のみ、設定パネル内をスクロール可能とする。

スマホ操作画面では、ピンチイン・ピンチアウトによるページ拡大・縮小を無効にする。

文字入力欄を除き、画面上のテキストは選択できない。

通常の画面タップでランダム打上を受け付けた際は、タップ地点から波紋を広げて受付を示す。波紋の大きさはブラウザが選択した花火サイズ、色は選択した基本色に合わせる。構造は考慮しない。

片手でも操作しやすいデザインとする。
